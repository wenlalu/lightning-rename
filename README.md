# 闪电重命名（Lightning Rename）

一款**纯本地、离线、轻量**的 Windows 批量重命名工具。基于 .NET Framework 4.0 开发，单文件约 48KB，无需安装任何额外运行时，可在十年前的旧电脑上流畅运行。
.NET Framework 4.0微软官方下载安装链接：https://dotnet.microsoft.com/zh-cn/download/dotnet-framework/thank-you/net40-offline-installer
> 面向公司内网/个人用户设计：**全程离线，零联网，零数据收集，零遥测上报**。

---

## 功能特性

- **六大重命名规则**（标签页形式、可组合叠加）：
  1. **查找替换**：主名 / 扩展名 / 完整名称三种作用域，可区分大小写。
  2. **添加前缀/后缀**。
  3. **删除字符**：按开头、末尾删除指定数量字符。
  4. **指定位置插入**：支持从头/从尾、是否算上扩展名。
  5. **编号**：起始值、步长、位数补零、前缀/后缀位置。
  6. **日期**：按当前日期格式化（年、月、日、中文等），可自定义分隔符。
- **其他能力**：大小写转换（大写/小写/首字母大写）、首尾空格清理、修改/删除扩展名。
- **实时预览**：所见即所得，改动项/未改动项均清晰加粗显示，冲突、非法名即时标红提示，绝不盲目改名。
- **文件夹递归**：支持"文件夹内容"一键载入；父文件夹改名后，内部文件路径自动校正。
- **两阶段事务式重命名 + 撤销（后悔药）**：先改临时名、再改新名，失败自动回滚；可一键撤销上一次重命名。
- **大数据量优化**：后台线程预览，2 万项姓名计算约 40ms；超过 2000 项时自动切换为"执行时检查磁盘"，避免卡顿。
- **完美中文路径 / 超长路径支持**（内部使用 `\\?\` 前缀的 Win32 API）。

## 运行环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | **Windows 7 (SP1)、Windows 8.1、Windows 10、Windows 11**（32 位 / 64 位均可） |
| 运行框架 | **.NET Framework 4.0 或更高**（Win7 需安装，Win10/11 系统自带 4.8） |
| 硬件 | 十年前旧电脑即可 —— Intel J1900、纯核显、**2GB 内存**均可流畅运行（约 48KB 单文件、内存占用毫MB 级） |
| 网络 | **无需联网**，可完全在隔离内网使用 |
| 权限 | 普通用户即可，无需管理员 |

> 旧电脑提示：若 Win7 未装 .NET Framework 4.x，请先从微软官方下载安装 `.NET Framework 4.0/4.x` 后再运行本程序。

## 快速上手

1. 双击运行 `闪电重命名_v1.0.0.exe`。
2. 点击工具栏 **「添加文件夹内容」** 或 **「添加文件」**，也可把文件/文件夹**直接拖入窗口**。
3. 在下方标签页勾选需要的规则并填写参数，**表格中会实时预览**每个文件的新名称。
4. 确认无误后点击绿色 **「开始重命名」**。
5. 如需恢复，点击 **「后悔药(撤销上次重命名)」**。

## 从源码构建

本项目由系统自带的 `.NET Framework 4.0` 编译器（`csc.exe`）即可编译，无需安装 Visual Studio。

```powershell
# 在仓库根目录执行
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物输出到 `发布版\` 目录。也可直接打开 `LightningRename\LightningRename.csproj` 用 Visual Studio 构建。

## 运行自动化测试

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run_tests.ps1
```

内置 81 项自动化断言，覆盖全部六组规则、边界值、冲突检测、真实磁盘重命名、撤销回滚等，全部通过。
